## รันจากซอร์สโค้ด: เปิด backend และใช้ Gemini บนเครื่อง

ส่วนนี้สำหรับผู้ที่ต้องการรันจากซอร์สโค้ดผ่านเบราว์เซอร์เท่านั้น **หากใช้ไฟล์ .exe ให้ข้ามส่วนนี้ได้**

ใช้ Node.js 20.12 ขึ้นไปสำหรับ backend แล้วรันในโฟลเดอร์โปรเจกต์:

```sh
node server.js
```

เปิด http://127.0.0.1:3000 แล้วไป **ข้อมูลโรงเรียนและ AI** ใส่คีย์จาก [Google AI Studio](https://aistudio.google.com/apikey) และเชื่อมต่อ มี Help วิธีรับคีย์ในแอป ไม่ต้องส่งคีย์ในแชต

backend ไม่ต้องติดตั้ง dependency เพิ่ม ตัวอ่าน ZIP ที่ browser ใช้อยู่ใน vendor แล้ว คีย์ในเว็บเก็บในหน่วยความจำ backend บนเครื่องจนปิดโปรแกรม ไม่เก็บใน localStorage แอป Windows มีตัวเลือกจำคีย์เข้ารหัส

อีกวิธีคือคัดลอก .env.example เป็น .env เฉพาะบนเครื่องแล้วกรอกคีย์ก่อนรัน ห้ามอัปโหลด .env จริง

โมเดลเริ่มต้นคือ gemini-3.5-flash-lite ราคาและโควตาอาจเปลี่ยน ให้ตรวจ [เงื่อนไข Google ปัจจุบัน](https://ai.google.dev/gemini-api/docs/pricing) กับบัญชีที่ใช้ ไม่รับประกันฟรีไม่จำกัด แอปไม่ได้เปิด billing ให้ หากใช้บัญชีชำระเงินอาจมีค่าใช้จ่าย

## GitHub Pages เป็นเดโม static เท่านั้น

GitHub ใช้เก็บโค้ดได้ และ GitHub Releases ใช้แจก .exe ได้ ส่วน Pages ไม่มี Gemini backend หรือ Word desktop แอปจะไม่ส่งคีย์จาก static hosting และไม่ฝังคีย์ไว้ใน JavaScript

Pages ใช้แม่แบบ รายการงาน คลัง และดาวน์โหลดเอกสารในเครื่องได้ ใช้ AI จริงผ่านแอป Windows หรือ backend บนเครื่อง หากต้องการให้หลายคนใช้ AI ผ่านเว็บ ต้องเพิ่ม backend HTTPS พร้อมระบบผู้ใช้และโควตา เป็นงานแยก

## ขอบเขตและความเป็นส่วนตัว

- อ่าน .docx ปกติสูงสุด 15 MB ไม่รองรับ .doc/.docm ไฟล์เข้ารหัส หรือ Word Strict XML
- แก้ข้อความเฉพาะย่อหน้าที่รองรับสูงสุด 80 ย่อหน้า/6,000 ตัวอักษรต่อชุด ไม่ใช่ทั้งไฟล์
- เมื่อยินยอม Word ส่งตัวอย่างข้อความสูงสุด 6,000 ตัวอักษรและย่อหน้าที่แก้ได้สูงสุด 6,000 ตัวอักษร พร้อมคำสั่ง ประเภท ระเบียบที่กรอกและสรุป XML ไป Google ไม่ส่ง ZIP ของไฟล์ ภาพ ตารางทั้งฉบับ หรือชื่อไฟล์
- ส่วนอื่นส่งข้อมูลที่กรอกตามหน้าที่ของโซน คลังส่งเฉพาะชื่อ/ข้อความบางส่วน
- ไฟล์ใหม่ไม่ทับต้นฉบับ ต้องตรวจใน Word เพราะความยาวข้อความอาจเปลี่ยนการแบ่งหน้า
- ร่างและรายการงานอยู่ในเครื่อง มีสำรอง/นำเข้าคลัง JSON ควรสำรองก่อนล้างข้อมูล

## สำหรับนักพัฒนา

ใช้ Node.js 22.12 ขึ้นไปสำหรับ development tools:

```sh
npm install
npm test
npm run desktop
```

สร้าง Windows executable:

```sh
npm run package:win
```

ผลอยู่ใน dist ถ้า NSIS มีปัญหาจาก path ยาว ให้ใช้ checkout สั้น เช่น C:/dev/classops-ai ไฟล์ executable ยังไม่ได้ลงนามดิจิทัล

หลังแก้ JavaScript:

```sh
node build.js
```

app.bundle.js และ standalone.html สร้างจาก source ไม่รวม backend/credentials ให้แก้ app.js, core.js, docx.js แล้ว build ใหม่

```text
index.html           UI ภาษาไทย
styles.css           รูปแบบหลัก
enhancements.css     เครื่องมือเพิ่มเติม
app.js               workflow และข้อมูลในเครื่อง
core.js              แม่แบบและกฎเอกสารใช้ซ้ำ
docx.js              อ่าน/แก้ DOCX โดยคงรูปแบบ
gemini.js            Google adapter และ validation (server-only)
server.js            backend เฉพาะเครื่อง, cache และขีดจำกัด
desktop/             Electron และตัวคำนวณหน้าผ่าน Word
vendor/              JSZip และใบอนุญาต
tests/               การทดสอบด้วยบริการจำลอง
```

ผ่าน 64 automated tests และตรวจเปิด Windows executable สำเร็จ Google/Word worker ในชุดทดสอบใช้ข้อมูลจำลอง ไม่รับรองบริการ Google หรือ Office ทุกบัญชี/เครื่อง
