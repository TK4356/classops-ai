✦ ให้ AI จัดการไฟล์ที่คุณใส่

AI ใช้แนวทางตามประเภทเอกสารและให้ระเบียบที่คุณใส่สำคัญกว่าแนวทางทั่วไป ไม่อ้างว่าผ่านระเบียบสถาบันเมื่อยังไม่มีคู่มือ ข้อเสนอการจัดหน้าเป็นรายการให้ตรวจ ไม่เปลี่ยนรูปแบบทั้งไฟล์หรือสารบัญอัตโนมัติ

AI ตรวจคำผิดในย่อหน้าที่รองรับได้สูงสุด 80 ย่อหน้า รวมย่อหน้าที่มีหลายส่วนข้อความ ไม่ใช่ทั้งไฟล์ ไม่แก้เนื้อหาในตาราง รูปภาพ ลิงก์ ฟิลด์ หรือสารบัญ แท็บ เส้นจุด และเลขหน้า คงฟอนต์ ระยะบรรทัด หน้ากระดาษ และส่วนที่ข้ามตามต้นฉบับ ตรวจข้อความก่อน/หลังและเลือกการแก้ไขก่อนบันทึก ต้องเชื่อม Gemini ได้จึงใช้ AI จริงได้

Google Gemini API

❔ Help — วิธีรับ Gemini API key
  1. เปิด Google AI Studio — API Keys ↗ และเข้าสู่ระบบด้วยบัญชี Google ของคุณ
  2. ยอมรับเงื่อนไขที่ Google แสดง หากมีคีย์เริ่มต้นให้แล้ว สามารถเลือกใช้คีย์นั้นได้
  3. หากยังไม่มีคีย์ กด Create API key แล้วเลือกโปรเจกต์ หากไม่พบโปรเจกต์ ไปที่ Projects → Import projects เพื่อนำเข้าโปรเจกต์ที่คุณมีสิทธิ์ใช้งาน แล้วกลับมาสร้างคีย์
  4. กด Copy เพื่อคัดลอกคีย์ แล้วกลับมาวางในช่อง Gemini API key ด้านล่าง ไม่ต้องส่งคีย์ในแชต
  5. เลือกโมเดล กด เชื่อม Google AI แล้วกด ตรวจการเชื่อมต่อ Google เพื่อดูสถานะ

คีย์เป็นความลับเหมือนรหัสผ่าน ห้ามเผยแพร่ใน GitHub หรือภาพหน้าจอ การใช้ Free tier มีโควตาและขึ้นอยู่กับบัญชี/โปรเจกต์ ไม่ใช่บริการฟรีแบบไม่จำกัด
